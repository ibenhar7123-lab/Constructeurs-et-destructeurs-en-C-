# Lab C++ : constructeurs, destructeur, RAII

- `exercice1_compte/compte.cpp` : CompteBancaire (regle des cinq, copy-and-swap)
- `exercice2_buffer/buffer.cpp` : Buffer dynamique (copie, deplacement, assignations)
- `exercice3_raii/raii.cpp`     : RAII, unique_ptr, exceptions dans les constructeurs

Compiler et executer : `make run`   |   Verifier les fuites : `make valgrind`   |   Nettoyer : `make clean`
